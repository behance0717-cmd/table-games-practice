# 桌游练习场 · 第二版

21 点、百家乐、骰宝，使用虚拟筹码的单机网页练习。

**开始玩：** https://behance0717-cmd.github.io/table-games-practice/

- 21 点：逐张发牌，庄家翻暗牌与补牌，加倍牌横放。
- 百家乐：暗牌依次落桌，点牌翻开或拖动牌角搓牌，第三张牌单独发出；支持全部开牌。
- 骰宝：多区域叠加筹码，撤销、清空、重复上局；盖盅摇骰后手动开盅，中奖区亮灯，逐区收注与派彩。
- 发牌、摇骰、筹码音效，可关闭；标准与快速节奏，适配减少动态效果的系统设置。
- 起始 10,000 筹码，无充值、提现、登录；已完成对局保存在当前浏览器，手机与电脑记录互不同步。

21 点是简化版：6 副牌，庄家软 17 停牌，Blackjack 净赢 3:2；不含分牌、保险与投降。百家乐采用 8 副牌、5% 庄赢佣金。骰宝每区 10–1,000，所有区域合计不得超过余额，具体规则与净赢倍率见游戏内玩法说明。

刷新或关闭会放弃尚未完成的对局并恢复到上一局完成后的筹码。游戏的开奖结果由随机数与固定规则决定，翻牌、搓牌和动画只控制揭晓过程。

流程研究参考：[Vegas Aces 荷官教学](https://www.vegas-aces.com/learn/03-big-baccarat-full-round-of-play-and-drawing-third-card/)；[Crown Sic Bo 实体流程](https://www.crownmelbourne.com.au/getsydmedia/38bb13e4-76ac-4392-a5c1-0c1044d5f121/crown-melbourne-gaming-table-games-sic-bo-rules.pdf?ext=.pdf)。不同场所的规程与赔率可能不同，本游戏采用说明中固定的练习规则。
